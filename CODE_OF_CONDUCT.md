# Code of Conduct

## Our community

We are committed to a respectful, constructive environment for everyone participating in this project — whether opening issues, reviewing pull requests, or submitting registry changes.

## Expected behavior

Examples of behavior that contributes to a positive environment:

- Showing honesty, respect and empathy toward other people
- Giving constructive feedback and receiving it professionally
- Respecting differing viewpoints and experiences
- Focusing on the technical issue or contribution rather than the person
- Helping make the project welcoming to new contributors
- Being tolerant of cultural and viewpoint differences among contributors from around the world
- Having patience with non-native English speakers

## Unacceptable behavior

Examples of unacceptable behavior include:

- Harassment, threats, or intimidation
- Insults, personal attacks, or discriminatory language
- Sexualized language or unwanted sexual attention
- Publishing someone's private information without explicit permission
- Trolling, deliberate provocation, or sustained disruption of discussions or reviews
- Any other conduct that a maintainer reasonably determines is inappropriate in a professional community setting

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub issues, pull requests, reviews, and discussions
- Repository documentation and associated project websites
- Any other official communication channels for the project

It also applies when an individual is representing the project in public spaces.

## Reporting

If you experience or witness unacceptable behavior, please report it privately.

**Do not** open a public GitHub issue for Code of Conduct reports.

Instead:

1. Email [wale@team.reclear.io](mailto:wale@team.reclear.io), or
2. Open a [private security advisory](https://github.com/reclear-io/llm-txts/security/advisories/new) on GitHub.

Include any relevant context, such as links, screenshots, or a description of what happened. Reports will be reviewed as promptly as we can and handled as confidentially as possible.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct. They may take any action they deem appropriate in response to a violation, including:

- Removing or editing comments
- Locking discussions or pull request threads
- Rejecting or closing contributions
- Temporarily restricting community access
- Permanently banning a participant from project spaces

Maintainers will review reports, evaluate context, and choose a response proportionate to the behavior. Keep in mind that maintainers are humans, with their own biases, who learn every day. If you disagree with an outcome, you may report again through the [Reporting](#reporting) paths above.
